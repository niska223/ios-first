Tutorial 4 iOS Game Project
Architecture Overview
This project is an iOS game application developed using Swift and
SwiftUI. The archived project uses a SwiftUI application entry point and
a main ContentView that provides navigation to the available game
modes and settings.
Features Included in This Archived Copy
- Tap Frenzy -- a timed tapping game where the player taps as
  quickly as possible.
- Light It Up -- a reaction-based game where the player responds
  to highlighted cards.
- Settings -- allows the user to adjust the round length.
- SwiftUI-based user interface and navigation.
Known Limitations
This is an earlier archived copy of the project. The later Tutorial 4
features demonstrated in the submitted video, including Quiz Rush, the
full tab-based shell, Stats/Charts, MapKit/Core Location, Daily
Challenge notifications, and score sharing, are not present in this
local archive.
The original development copy and its incremental Git history were
created on the campus development machine and are not included in this
archive.
Reflection
Developing the game application helped me practise SwiftUI state
management, navigation, reusable views, timers, game logic, and user
interaction. Building the different game modes also helped me understand
how an iOS application can organise multiple features while keeping the
interface simple for the user.
